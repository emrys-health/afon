# Demo 6/8/2026

# Prepare stack

Deploy the aws full stack:
```shell
./afon.sh -a exec --exec-class ops.DeployAwsFullStackMain
```
The deployment takes ~20-30 mins, of which ~5-10 mins for dns propagation of the domains. 

Register existing cloud storage tables to Polaris, run:
```shell
./afon.sh -a exec --exec-class ops.RegisterPolarisTableMain --exec-args "aws aws acceptancetests AwsAccessSpec s3://emrys-afon-bucket/acceptancetests/AwsAccessSpec251117511401/metadata/00000-685ec54b-684f-48cb-bb58-6ae6aacb92e6.metadata.json <user_polaris_id> <user_polaris_secret>"
```
If user polaris credentials are not specified, it defaults to the ones specified in `config/secrets.properties`.

The table was created by `afon-acceptance` tests. The salient file in any Iceberg table is the `*.metadata.json` one.

# Prepare monitoring

Setup monitoring as describe in [monitoring](./docs/monitoring.md).

- Grafana:  [http://localhost:3000](http://localhost:3000)
- Hubble:   [http://localhost:12000](http://localhost:12000)

# Run acceptance 

Run acceptance tests - this should take ~2 mins and walks through the scenarios

Acceptance tests are run by
```shell
./afon.sh -a build -p acceptance
```
The scenarios are outputted to console and can be also inspected (post-run) by
```shell
cat afon-acceptance/target/surefire-reports/scenarios.txt
```

# Login to Jupyter 

Login to [http://emrysjupyter.click](http://emrysjupyter.click) and follow the OAuth link to fire up your pod, 
authenticating with one of the users defined in `config/users.csv`.  
`DeployAwsFullStackMain` will have configured these users for AWS.

Open application bash on pod.  Launch firefox.  Open URL http://localhost:8888 on firefox.

You should see it with status `ContainerCreating` when you run 
```shell
kubectl get pods
```
It may take a minute or two if the container image is not cached.

Copy notebook on the user pod (eg the `will` pod):
```shell
kubectl cp demo/notebooks/AwsSmokeTest.ipynb $(kubectl get pods | grep will | awk '{print $1}'):/home/jovyan
```
The notebook will appear in your Jupyter pod.

### Logging

Hubble logs: search network flows
```shell
hubble observe --follow > /tmp/hubble-flows
```

```shell
tail -f /tmp/hubble-flows | grep 185.230.220.104
```

Polaris logs:  search user activity
```shell
kubectl logs -f $(kubectl get pods | grep polaris | awk '{print $1}')  | grep -E "principalName=will"
```

Spark connector logs:  search acceptancetests
```shell
kubectl logs -f $(kubectl get pods | grep spark-connector | awk '{print $1}')  | grep -E "scan-report|Authorization: Bearer"
```

Show CPU usage by node
```shell
kubectl top nodes
```

Describe pod
```shell
kubectl describe pod $(kubectl get pods | grep will | awk '{print $1}') 
```
