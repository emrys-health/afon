# Deploying the stack

Deploy AWS full stack:
```shell
./afon.sh -a exec --exec-class ops.DeployAwsFullStackMain
```

If you need to add tables to Polaris, run something like:
```shell
./afon.sh -a exec --exec-class ops.RegisterPolarisTableMain --exec-args "aws aws acceptancetests AwsAccessSpec s3://emrys-afon-bucket/acceptancetests/AwsAccessSpec251117511401/metadata/00000-685ec54b-684f-48cb-bb58-6ae6aacb92e6.metadata.json <user_polaris_id> <user_polaris_secret>"
```
If user polaris credentials are not specified, it defaults to the ones specified in `config/secrets.properties`.

The table was created by `afon-acceptance` tests. The salient file in any Iceberg table is the `*.metadata.json` one.

# Login to Jupyter

In your browser, open URL [emrysjupyter.click](http://emrysjupyter.click) and follow the OAuth link to authenticate as one of the users configured in `config/users.csv`.  Let's say, it's `phil`.  Once authenticated the `phil` pod will be created.

You should see it with status `ContainerCreating` when you run:
```shell
kubectl get pods
```
It may take a minute or two if the container image is not cached.

`DeployAwsFullStackMain` will have configured these users for AWS but 
if you need them for other Catalogs, look at `ConfigureKeyCloakUsersMain`.

If you want to put a notebook on, say, the `phil` Jupyter pod, run:
```shell
kubectl cp demo/notebooks/CrossCloudJoinExample.ipynb $(kubectl get pods | grep phil | awk '{print $1}'):/home/jovyan/
```
Give it a second or two and your notebook will appear in the Jupyter pod. 

Once in the Jupyter pod, open a bash terminal and fire up firefox.   Open `http://localhost:8888` and you'll see the notebook you copied available for use.

# Tearing down the stack

When you're finished, tear down the stack:
```shell
./afon.sh -a tofu-destroy
```
