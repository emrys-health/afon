# Deploying the stack

Run:
```shell
./afon.sh -a exec --exec-class ops.DeployAwsFullStackMain
```

If you need to add tables to Polaris, run something like:
```shell
./afon.sh -a exec --exec-class ops.RegisterPolarisTableMain --exec-args "AWS acceptancetests AwsAccessSpec s3://emrys-afon-bucket/acceptancetests/AwsAccessSpec251117511401/metadata/00000-685ec54b-684f-48cb-bb58-6ae6aacb92e6.metadata.json emryspolaris.click will s3cr3t"
```
(This is a table that was created running the `afon-acceptance` tests.
The salient file in any Iceberg table is the `*.metadata.json` one).

# Login to Jupyter

In your browser, open URL [emrysjupyter.click](http://emrysjupyter.click) and follow the OAuth link to authenticate as one of the users configured in `config/users.csv`.  Let's say, it's `phil`.  Once authenticated the `phil` pod will be created.

You should see it with status `ContainerCreating` when you run:
```shell
kubectl get pods
```
It may take a minute or two if the container image is not cached.

`DeployAwsFullStackMain` will have configured these users for AWS but 
if you need them for other Catalogs, look at `OnboardAllUsersMain`.

If you want to put a notebook on, say, the `phil` Jupyter pod, run:
```shell
POD=$(kubectl get pods | grep phil | awk '{print $1}') # looking up 'phil' Jupyter pod
kubectl cp demo/notebooks/CrossCloudJoinExample.ipynb $POD:/home/jovyan/CrossCloudJoinExample.ipynb
```
Give it a second or two and your notebook will appear in the Jupyter pod. 

When you're finished:
```shell
./afon.sh -a tofu-destroy
```
