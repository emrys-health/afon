# Deploying the environment

Run:
```shell
./afon.sh -a exec --exec-class ops.DeployAwsFullStackMain
```

If you need to add tables to Polaris, run something like:
```shell
./afon.sh -a exec --exec-class ops.RegisterPolarisTableMain --exec-args "AWS acceptancetests AwsAccessSpec s3://emrys-afon-bucket/acceptancetests/AwsAccessSpec251117511401/metadata/00000-685ec54b-684f-48cb-bb58-6ae6aacb92e6.metadata.json emryspolaris.click will s3cr3t"
```
(This is just an old table that `afon-acceptancetests` created.
The salient file in any Iceberg table is the `*.metadata.json` one).

Then, login to `emrysjupyter.click` and follow the OAuth link to fire up your pod.
You should see it with status `ContainerCreating` when you run `kubectl get pods`.
It may take a minute or two if the container image is not cached.

User names and passwords can be found in `config/users.csv`.
`DeployAwsFullStackMain.java` should have configured these users for AWS but if you need them for other Catalogs, look at `OnboardAllUsersMain.java`.

Let's assume you want to put a notebook on, say, the `phil` pod. In the `notebooks` subdirectory, run:
```shell
POD=$(kubectl get pods | grep phil | awk '{print $1}') # swap 'phil' for 'will' if you want his pod
kubectl cp ./CrossCloudJoinExample.ipynb $POD:/home/jovyan/CrossCloudJoinExample.ipynb
```
Give it a second or two and your notebook will appear in your Jupyter pod. 

When you're finished, go to `afon-ops/cdktf.out/stacks/aws/` and run `tofu destory --auto-approve`.
