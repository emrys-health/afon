# Afon CLI

## Afon CLI distribution

The Afon CLI distribution is the binary distribution allowing you use Afon via a CLI interface, 
**without access to the source codebase**.

### Using Afon CLI 

Refer to [cli documentation](./cli/cli.md) for all details on how to install, configure and run the CLI distribution,

### Building the Afon CLI 

If you do have access to the source code, you can also build the CLI. Refer to the [build](build.md) documentation.
