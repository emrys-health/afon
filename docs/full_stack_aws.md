If you really wanted to, you could run the individual steps by hand. They are:

### Clean the local AWS directory (if it exists)
Delete `./terraform.aws*`

### Deploy Spark in AWS
In the top level directory 
run
```shell
mvn  exec:java -Dexec.mainClass=health.emrys.afon.cdk.aws.PrometheusClusterDeploy 
```

In `cdktf.out/stacks/aws` 
run
```shell
tofu init
```

In `cdktf.out/stacks/aws` 
run
```shell
tofu apply --auto-approve -parallelism=20
```

### Wait for DNS servers
Wait for DNS servers to recognise emryspolaris.click. On a Unix system, running:
```shell
dig A emryspolaris.click +short
```

will show you the IP address when the DNS servers have updated.

```shell
      echo $LB
      aws elbv2 delete-load-balancer  --load-balancer-arn $LB
    } done
    echo destroying internet gateways...
```
