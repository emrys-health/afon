# Deploying the environment

Deploy the aws full stack:
```shell
./afon.sh -a exec --exec-class ops.DeployAwsFullStackMain
```
The deployment takes ~20-30 mins, of which ~5-10mins for dns propagation of the domains. 

Register existing cloud storage tables to Polaris, run something like:
```shell
./afon.sh -a exec --exec-class ops.RegisterPolarisTableMain --exec-args "AWS acceptancetests AwsAccessSpec s3://emrys-afon-bucket/acceptancetests/AwsAccessSpec251117511401/metadata/00000-685ec54b-684f-48cb-bb58-6ae6aacb92e6.metadata.json emryspolaris.click will s3cr3t"
```

The table was created by `afon-acceptance` tests. The salient file in any Iceberg table is the `*.metadata.json` one.

Run acceptance tests - this should take 3 minutes and walks through the scenarios

Login to `emrysjupyter.click` and follow the OAuth link to fire up your pod, authenticating with username/password defined in users.csv.

You should see it with status `ContainerCreating` when you run 
```shell
kubectl get pods
```
It may take a minute or two if the container image is not cached.

Usernames and passwords can be found in `config/users.csv`. 

`DeployAwsFullStackMain` will configure these users for AWS. If needed for other catalogs: 

```shell
./afon.sh -a exec --exec-class ops.OnboardAllUsersMain --exec-args "<polaris.domain> <catalog> <jupyter.domain>"
```
where `catalog={AZURE|GCP}` and polaris and jupiter domains are catalog specific.

Copy notebook on the user pod (eg `will` pod):
```shell
POD=$(kubectl get pods | grep will | awk '{print $1}') 
kubectl cp docs/demo/notebooks/AwsSmokeTest.ipynb $POD:/home/jovyan
```
The notebook will appear in your Jupyter pod.

When you're finished, bring down stack: 

```shell
./afon.sh -a tofu-destroy
```

### Logging

```shell
hubble observe --follow > /tmp/hubble-flows
```

```shell
tail -f /tmp/hubble-flows | grep 185.230.220.104
```

Polaris logs
```shell
kubectl logs -f $(kubectl get pods | grep polaris | awk '{print $1}')  | grep -E grep "principalName="
```

Spark connector logs
```shell
kubectl logs -f $(kubectl get pods | grep spark-connector | awk '{print $1}')  | grep -E "scan-report|Authorization: Bearer"
```

Show CPU usage by node
```shell
kubectl top nodes
```

Describe pod
```shell
kubectl describe pod <name>
```
