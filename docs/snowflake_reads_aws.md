To run the actual deployment, run:
```shell
mvn  compile -Dexec.mainClass=health.emrys.afon.opsDeploySnowflakeReadingAwsViaAwsMain  exec:exec -Pdemo
```


The steps to run are:
1. clean_aws

1. emryspolaris_spark_talks_to_aws

If the job fails on a given step, you can add this switch to the mvn command above:

`-Dexec.args="STEP_FROM_LIST_ABOVE"`

and the steps will continue starting at that one and the goal should be `exec:exec` not `exec:java`.

For example:

`mvn compile -Pdemo -Dexec.mainClass="health.emrys.afon.demo.DeploySnowflakeReadingAwsViaAwsMain"  -Dexec.args="snowflake_reads_aws"  exec:exec`

### Summary of this deployment

This deployment uses Spark running locally but talking to the AWS Spark Connector to create an
Iceberg table in AWS. This table is automatically registered in the AWS Polaris as part of
the creation process.

We then point Snowflake at this Polaris running in our real estate and run a SF query against it.
