# Contributing to Afon

Thank you for your interest in contributing to Afon.  Contributions of all kinds are welcome: bug reports,
enhancements, new features, documentation, testing and code review.

The full guide is in [docs/contributing](docs/contributing/README.md):

- [Contribution criteria](docs/contributing/README.md#contribution-criteria-how-we-maintain-quality-together): licensing, quality, security and conduct
- [Creating issues](docs/contributing/issues.md)
- [Creating pull requests](docs/contributing/pull_requests.md)
- [Testing](docs/contributing/testing.md)

In short:

1. Find, or [create](docs/contributing/issues.md), an issue, and agree the approach in it before starting work.
2. Keep your change small and focused on that issue, with tests.
3. Make sure the tests your change needs pass: the unit tests always, and the acceptance and smoke tests
   depending on what you change.  See [which tests a change needs](docs/contributing/testing.md#which-tests-a-change-needs).
4. Open a [pull request](docs/contributing/pull_requests.md).

To report a security vulnerability, do **not** open an issue: follow the [security policy](SECURITY.md).

All contributors are expected to be respectful and constructive: see [Conduct](docs/contributing/README.md#conduct).
