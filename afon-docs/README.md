
### Documentation

To keep the documentation in lock-step with the tests, it is now autogenerated. 
You'll find it in the [docs](../docs) directory. 
Most are not checked in just in case it contains sensitive data.
So, generate them with:
```shell
mvn compile -Dexec.mainClass=health.emrys.afon.docs.DocumentFullStackAwsMain exec:java
mvn compile -Dexec.mainClass=health.emrys.afon.docs.DocumentGcpPolarisMain exec:java
mvn compile -Dexec.mainClass=health.emrys.afon.docs.DocumentAzurePolarisMain exec:java
mvn compile -Dexec.mainClass=health.emrys.afon.docs.DocumentExternalCatalogsMain exec:java
```
etc.

Note that `DocumentExternalCatalogsMain` deploys both AWS and Azure infra.
