
### Documentation

To keep the documentation in lock-step with the tests, it is now autogenerated. 
You'll find it in the [docs](../docs) directory. 
Most are not checked in just in case it contains sensitive data.
So, generate them with:

```shell
mvn exec:exec -Pexec -Dexec.mainClass=health.emrys.afon.docs.DocumentFullStackAwsMain
mvn exec:exec -Pexec -Dexec.mainClass=health.emrys.afon.docs.DocumentGcpPolarisMain
mvn exec:exec -Pexec -Dexec.mainClass=health.emrys.afon.docs.DocumentAzurePolarisMain
mvn exec:exec -Pexec -Dexec.mainClass=health.emrys.afon.docs.DocumentExternalCatalogsMain
```
etc.

Note that `DocumentExternalCatalogsMain` concerns both AWS and Azure.
