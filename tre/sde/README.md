# Scope

The scope of the docs in SDE is to detail the configuration required at SDE level.

# Network Whitelisting

To minimize the risk of token exfiltration leading to data being viewed outside the TRE
(see [this](https://github.com/emrys-health/afon-core/issues/162) ticket),
the SDEs are recommended to add the TRE's IP address to their whitelist.
